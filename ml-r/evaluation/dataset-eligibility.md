Sources are the [Mendeley release](https://data.mendeley.com/datasets/btm76zndnt/3), [Creative Commons BY 4.0 deed](https://creativecommons.org/licenses/by/4.0/), [Kaggle version 1](https://www.kaggle.com/datasets/adisongoh/it-service-ticket-classification-dataset/versions/1), [Kaggle publisher metadata](https://www.kaggle.com/api/v1/datasets/view/adisongoh/it-service-ticket-classification-dataset), [Creative Commons CC0 1.0 deed](https://creativecommons.org/publicdomain/zero/1.0/), [Hugging Face release](https://huggingface.co/datasets/benjaminmacklin/IT_Support_V2), and [pinned MIT license file](https://huggingface.co/datasets/benjaminmacklin/IT_Support_V2/resolve/bbaf7b99593a9492594d5be414619c1ad33e1730/License).

Mendeley v3 files were resolved through its public manifest and checked against the publisher's file digests. The audited NLU inputs were `issues.csv` and `sample_utterances.csv`. Status histories, snapshots, holiday tables, and manager appraisal spreadsheets describe workflow or scoring rather than original issue descriptions. Kaggle's API delivered the original v1 archive directly. Its sole CSV is `all_tickets_processed_improved_v3.csv`, and that filename's `v3` is distinct from Kaggle's release version. Hugging Face's dataset configuration selects the pinned JSONL as the train input. The audit used that source file rather than counting the repository's Parquet representation as additional examples.

Pattern matches in published files are screening signals. Privacy review still needs to cover names, internal systems, credentials, and contextual identifiers. A dataset license does not establish consent for those fields. The previous rejected dataset was excluded from all work.
